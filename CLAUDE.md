## Commands

```bash
# One-time: split IMDb export into films and TV
python split_ratings.py

# Films pipeline (run from films/)
pip install -r requirements.txt
python src/ingest.py     # download + preprocess MovieLens 25M (~5–15 min, run once)
python src/match.py      # find 400 nearest neighbours (~1 min, run once)
python src/tmdb_recent.py        # fetch post-2020 candidates via TMDB (run once, needs TMDB_API_KEY)
python src/tmdb_recent.py --force  # re-fetch (after updating ratings or monthly for new releases)
python src/recommend.py
python src/recommend.py --no-interactive   # skip questions
python src/recommend.py --debug            # full scored candidate list

# Shows pipeline (run from shows/)
pip install -r requirements.txt
python src/ingest.py     # fetch Trakt user ratings + show metadata (run once, needs TRAKT_CLIENT_ID; 1–2 h)
python src/ingest.py --out-dir data_new   # rebuild into a separate folder, then swap with data/
python src/match.py      # find 200 nearest neighbours (run once or after replacing films/my_ratings.csv)
python src/recommend.py
python src/recommend.py --no-interactive
python src/recommend.py --debug

# Streamlit dashboard (run from recs/)
pip install -r requirements_app.txt
streamlit run app.py

# Stremio addon (run from recs/)
python addon.py              # serves on port 7000; install via http://localhost:7000/manifest.json
python addon.py --port 7777

# Export static site data
python scripts/export_site.py          # writes docs/data/recs.json
python scripts/export_site.py --output path/to/custom.json

# Offline evaluation (run from recs/): hides each fold of your ratings, re-runs
# matching + candidates + scoring, reports reach and liked-vs-disliked AUC
python scripts/evaluate.py                 # both pipelines, 5 folds (~1.5 min)
python scripts/evaluate.py --only shows --folds 10
```

Run `scripts/evaluate.py` before and after any change to matching, candidate or scorer logic. Shows AUC moves ±0.05 between seeds (only ~10 disliked shows), so smaller differences there are noise.

## Films system architecture (`films/`)

Five-stage pipeline:

1. **`src/ingest.py`** — Downloads MovieLens 25M (~250 MB), filters to users/movies with ≥50 ratings, saves three parquet files: `processed_ratings`, `movies_meta`, `movie_tags`. Also computes `imdb_ratings.parquet` — uses OMDb API if `OMDB_API_KEY` is set in `.env`, otherwise scales MovieLens average ratings as a proxy.

2. **`src/match.py`** — Loads `my_ratings.csv` (IMDb export, 1–10 scale), bridges to MovieLens IDs via `links.csv` imdbId, computes Pearson correlation against every active MovieLens user (0.5–5.0 scale) with `MIN_OVERLAP=10`, shrunk by `min(overlap, SHRINK_OVERLAP=50) / 50` (raw value kept as `raw_correlation`). Saves top `K_NEIGHBOURS=400`. No genre reranking — the old prestige-genre rerank measurably hurt. `get_era_weighted_neighbours()` reruns the same matching on era-only films (`ERA_MIN_OVERLAP=5`) for session-scoped era filtering.

3. **`src/candidates.py`** — Candidates are unseen films rated (any score) by ≥ `MIN_NEIGHBOUR_RATINGS=2` positively-correlated neighbours. `diversity_score` (the candidate ranking, 0–1) = `QUALITY_WEIGHT=0.5` × percentile of `quality_score` (mean deviation from each rater's own average, across all MovieLens raters) + 0.5 × percentile of `weighted_score` (the same deviation among neighbours, similarity-weighted, × n/(n+`PREDICTION_SHRINK=5`)). `recommender_count` = neighbours rating it ≥4★. Merges `imdb_ratings.parquet` and `tmdb_enriched.parquet` (runtime is coalesced from both); **drops titles with no TMDB data — these are TV series MovieLens lists as films**. Applies session filters (era up to `DATASET_MAX_YEAR=2023`, famousness, runtime). Contains the `ALREADY_SEEN` set (~280 normalised titles).

4. **`src/scorer.py`** — Deterministic taste scorer. **All tunable weights are named constants at the top of the file.** Six components: genre score (capped ±20/15), franchise penalty (−40 hard veto), IMDb gap signal via `imdb_gap_signal()` (±12/8/−10), positive keyword tags (cap +15), negative keyword tags (cap −20), era bonus (±2–5), plus a session mood modifier (±3–9). Badges: `safe_bet` (≥30), `wild_card` (≥15), or `skip`. **Picks** (`score_candidates()`): safe bets = top `diversity_score` among collaborative candidates, vetoing franchise, animation and documentary-only titles (`SAFE_BET_*_VETO` flags); wild cards = best `taste_score` among the less-famous half of the pool; recent picks = best 2020+ `taste_score`. Franchise keywords match whole words only (substrings caught "marvelous"), sequel markers match the title only.

5. **`src/recommend.py`** — Entry point. Interactive 5-question session via `get_session_preferences()`. Calls `get_era_weighted_neighbours()` when era filter is set (session-only, not saved). `--no-interactive` skips questions. `--debug` shows all 80 candidates. Saves JSON to `data/recommendations_YYYY-MM-DD.json`.

6. **`src/session.py`** — `SessionPrefs` dataclass. Imported by both `recommend.py` and `candidates.py` to avoid circular imports.

## Shows system architecture (`shows/`)

Same five-stage pipeline, adapted for Trakt TV data:

1. **`src/ingest.py`** — Seeds from every show I rated ≥ `SEED_MIN_RATING=7` (falls back to `SEED_SLUGS` when no `shows_meta` exists yet). Collects candidate users from `PAGES_PER_SEED` pages of each seed's public lists and comments, fetches ratings (most-seen users first) and keeps up to `MAX_USERS=3000` who rated ≥ `MIN_MY_OVERLAP=5` of my shows. Fetches metadata only for shows rated by ≥ `META_MIN_RATERS=3` kept users (plus my own), reusing `data/shows_meta.parquet`. Progress is checkpointed in `<out-dir>/ingest_checkpoint/`, so interrupted runs resume. `--out-dir` writes elsewhere (folders matching `shows/data_*/` are gitignored) so the live data stays untouched until you swap it in.

2. **`src/match.py`** — `load_my_ratings()` reads the TV Series / TV Mini Series rows of `films/my_ratings.csv` (the same IMDb export films uses) and bridges them to Trakt slugs via `shows_meta.imdb_id`, printing any it can't match. Also defines `TV_ALREADY_SEEN`, extra slugs to exclude on top of rated shows. Computes Pearson correlation with `MIN_OVERLAP=5`, shrunk by `min(overlap, SHRINK_OVERLAP=20) / 20` so chance agreement on a handful of shows can't outrank real matches (raw value kept as `raw_correlation`). Reranks by genre alignment using same `0.6 × correlation + 0.4 × genre_alignment` formula. Saves top `K_NEIGHBOURS=200` neighbours.

3. **`src/candidates.py`** — Gets shows rated ≥8.0 (Trakt 1–10 scale) by neighbours. `MIN_RECOMMENDER_COUNT=3`, `MIN_AVG_RATING=7.0`. Applies session filters: era (year), status (ended/ongoing), episode count, and famousness by `trakt_votes`. Top 60 candidates by diversity score.

4. **`src/scorer.py`** — Same deterministic structure as films scorer. Signals: `TV_GENRE_SCORES` (Trakt genre strings, capped at 18), `TV_GENRE_COMBINATIONS` combos, Trakt community rating signal (≥8.5 → +6, <6.5 → −8), status signal (ended/cancelled → +4), neighbour consensus signal, episode count signal (6–60 eps sweet spot → +3, >150 → −3), keyword signals, mood modifier. Picks are chosen in `score_and_select()`: **safe bets and recent picks are ranked by the neighbour signal (`diversity_score`)**, with `taste_score < VETO_THRESHOLD=15` as a veto, because offline evaluation shows the neighbour signal predicts my ratings much better (AUC ~0.78 vs ~0.68). **Wild cards** are the best `taste_score ≥ 24` among the less-voted half of the pool (`WILD_CARD_MAX_VOTES_QUANTILE`), for discovery.

5. **`src/recommend.py`** — Same entry point pattern. 5-question interactive session: era, status (finished vs ongoing), episode commitment (≤15 / ≤50 / any), obscurity, mood. Saves JSON to `data/tv_recommendations_YYYY-MM-DD.json`.

6. **`src/session.py`** — `SessionPrefs` dataclass with `era_min_year`, `status_filter`, `max_episodes`, `exclude_famous`, `famous_votes_threshold`, `mood`.

## Streamlit dashboard (`app.py` + `app/`)

`streamlit run app.py` from the repo root. On cold-start it loads the latest `recommendations_*.json` / `tv_recommendations_*.json` from each `data/` folder so the UI is populated without re-running the pipeline.

`app/pipeline.py` is the critical integration point: because `films/src` and `shows/src` contain modules with identical names (`session`, `candidates`, `scorer`, etc.), `_activate_films()` / `_activate_shows()` flush all those names from `sys.modules` and swap `sys.path` before each import. **Never import these modules directly at module level in any `app/` file** — always go through `run_films()` / `run_shows()` or call `_activate_*()` first.

`app.py` defines local `FilmsPrefs` / `ShowsPrefs` dataclasses that mirror the ones in `films/src/session.py` and `shows/src/session.py`; this avoids the `sys.path` games in the UI layer. `addon.py` does the same. If you change a `SessionPrefs` field, update all three places.

Three tabs:
- **Tonight's Picks** — safe bets + wild cards from the latest pipeline run
- **All Candidates** — interactive Plotly scatter (taste score vs diversity), click a point to inspect; sortable dataframe below
- **Taste Profile** — bar charts of avg rating per genre from the film and TV rows of `my_ratings.csv`

## Stremio addon (`addon.py`)

Standalone HTTP server (no Streamlit dependency) that exposes two Stremio catalogs — `personal-films` and `personal-shows` — identified by IMDB IDs. On startup it runs both pipelines with default prefs and builds the catalog in memory; requests are served statically after that. Install by pasting `http://localhost:7000/manifest.json` into Stremio's "Add addon from URL". For LAN access from a phone, find your Mac's IP with `ipconfig getifaddr en0`.

## Static site (`scripts/export_site.py` + `docs/`)

`python scripts/export_site.py` runs both pipelines for two era variants each (`all` and `post_2020`), bundles results into `docs/data/recs.json`, and prints a summary. The `docs/` folder is a static GitHub Pages site (vanilla JS in `app.js`) that reads `recs.json`. Re-run this script to refresh the site data before pushing.

## Key data details

### Films
- `links.csv` imdbId values may have leading zeros stripped — `match.py` normalises both sides with `lstrip("0")` before merging.
- MovieLens titles include year suffix (`"Toy Story (1995)"`) and article-last format (`"Dark Knight, The"`). The `norm()` function in `candidates.py` handles both.
- `imdb_ratings.parquet` stores `imdb_rating`, `imdb_votes`, and `runtime`. If using the proxy path (no OMDb key), `runtime` is `None` and `imdb_votes` is the MovieLens rating count.
- If `data/imdb_ratings.parquet` was generated before `imdb_votes`/`runtime` columns were added, delete it and re-run `src/ingest.py`.

### Shows
- TV ratings come from the TV rows of `films/my_ratings.csv`, matched to Trakt by IMDb ID. To add new ratings: replace that file with a fresh IMDb export and re-run `python src/match.py`. A rated show missing from `shows_meta.parquet` is reported as unmatched and ignored.
- Trakt slugs are used as primary keys throughout (not numeric IDs).
- Rated shows are always excluded from candidates; `TV_ALREADY_SEEN` in `match.py` lists additional slugs to exclude.

## Tuning the scorer

### Films (`films/src/scorer.py`)
- `GENRE_SCORES` — per-genre base points
- `COMBO_BONUSES` — list of `(frozenset, bonus, reason_string)` tuples
- `imdb_gap_signal()` — standalone function, edit thresholds directly
- `POSITIVE_KEYWORDS` / `NEGATIVE_KEYWORDS` — tag-matching signals
- `SAFE_BET_THRESHOLD` / `WILD_CARD_THRESHOLD` — badge cutoffs (currently 30/15); safe bets follow `diversity_score` (see `films/src/candidates.py`), with `SAFE_BET_*_VETO` flags

Run `python src/recommend.py --debug` after any weight change to verify Drama+Crime films score higher than Action+Sci-Fi films.

### Shows (`shows/src/scorer.py`)
- `TV_GENRE_SCORES` — per-genre base points (Trakt genre strings, lowercase)
- `TV_GENRE_COMBINATIONS` — list of `(frozenset, bonus, reason_string)` tuples
- `TRAKT_RATING_HIGH` / `TRAKT_RATING_LOW` — community rating thresholds
- `POSITIVE_KEYWORDS` / `NEGATIVE_KEYWORDS` — overview keyword signals
- `SAFE_BET_THRESHOLD` / `WILD_CARD_THRESHOLD` — classification cutoffs (currently 38/24); `VETO_THRESHOLD` (15) blocks neighbour-ranked picks

Run `python src/recommend.py --debug` after any weight change to verify Drama+Crime shows score higher than Reality/Game-show content, and `python scripts/evaluate.py --only shows` to check the ranking didn't get worse.
